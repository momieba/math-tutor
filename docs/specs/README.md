# Specs (Feature-Pläne)

Hier legt der devflow-Planer für jede nicht-triviale Änderung einen Plan ab: `YYYY-MM-DD-<slug>.md` mit Ziel, Nicht-Zielen, Akzeptanzkriterien, Schritten, Teststrategie, Risiken und Doku-Auswirkungen.
Pläne werden vor der Umsetzung freigegeben und im Pull Request verlinkt. Sie bleiben als Nachweis im Repo.
